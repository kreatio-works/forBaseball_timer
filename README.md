# 野球タイマー

試合時間・インターバル・フリータイマーと、投手の球数カウンターをまとめた1ファイルのWebアプリです。
インストール不要で、スマホのブラウザで開くだけで使えます。

## 置きかた（GitHub Pages）

1. GitHubで新しいリポジトリを作る（Publicにする）
2. 次のファイルをまとめてアップロードする（同じ階層に置く）
   - `index.html`（アプリ本体）
   - `manifest.json`
   - `icon-192.png` / `icon-512.png` / `apple-touch-icon.png` / `favicon.png`（アイコン）
3. リポジトリの Settings → Pages → Source を「Deploy from a branch」、Branch を `main` / `(root)` にして保存
4. 1〜2分待つと `https://ユーザー名.github.io/リポジトリ名/` で開けるようになる

このURLをLINEなどで配れば、全員が同じアプリを使えます。

## スマホでの使いかた

- iPhone：Safariで開く → 共有ボタン → 「ホーム画面に追加」
- Android：Chromeで開く → メニュー → 「ホーム画面に追加」

アプリのように一発で起動できます。アイコンとアプリ名も表示されます。

時間の設定は「−／＋」で変えられます。秒は10秒ずつ動きます。

## 記録の保存について

- 投手・球数・設定・試合の開始終了時刻は、**開いた端末のブラウザの中だけ**に保存されます
- サーバーには何も送られません。誰かの記録が他の人に見えることもありません
- 逆に、**端末どうしで同期はしません**。球数を数える人は毎回同じ端末で数えてください
- Safariの「履歴とWebサイトデータを消去」を実行すると、記録も消えます
- 試合ごとに「一覧」→「コピー」でスプレッドシートやLINEに貼っておくと安心です
- 設定 →「記録の保存」→「書き出す」で、全データをテキストとしてコピーできます

## 主な機能

**タイマー**
- 試合時間（初期値2時間・変更可）。0になっても止まらず、超過時間を赤で表示
- インターバル（初期値5分）。開始すると試合時間が自動で止まり、終了後の再開は自動／手動を選択
- フリータイマー。計測（数え上げ）と1〜10分などのカウントダウンを切り替え可能
- 「開始」で開始時刻、「試合終了」で終了時刻を記録。タップでコピー

**球数**
- 投手ごと・イニングごとにカウント。「この回」「累計」を大きく表示
- 残りが設定値（初期値10球）を切ると「残り○球」の大きな表示に切り替わり、色と音で知らせます
- 1日の上限・連続2日間の上限は設定で変更できます（**所属連盟の最新のガイドラインに合わせてください**）
- 前日・一昨日の球数を手入力でき、連投の合計と「3日連続の登板」の注意を表示
- 「一覧」で投手×イニングの表。過去の日付も見返せます

## 設定の変更

画面右上の歯車から、試合時間・インターバル・球数の上限・音や振動・画面の常時オンを変更できます。
変更した内容はその端末に保存され、次回も引き継がれます。
